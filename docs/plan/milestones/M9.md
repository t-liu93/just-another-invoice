## 目标与范围
- **目标**：把单据交付给客户——生成一套干净 PDF（发票/报价，渲染前清洗用户输入），可下载；复用 M1 SMTP 把单据邮件 + PDF 附件发出并留 Email log。
- **纳入（IN）**：
  - **PDF 生成**：一套模板（**Jinja2 + WeasyPrint 候选**，JIT 时定）；抬头/logo/行项目/税/合计/内容块/Notes 全渲染；**用户输入进 PDF/HTML 前清洗**（XSS/SSRF，红线 7，沿用 InvoiceShelf sanitizer 思路）；下载端点（**无公开链接、手动发**）。
  - **邮件**：复用 M1 SMTP；单据**邮件正文模板 + 占位符**（发票号/客户/金额/到期日…）；**Email log**（发送记录，无已读回执）；把 PDF 作附件发出。
  - **收款收据 PDF**（低优，软依赖 M7）：对一张/多笔收款出收据。
  - **PDF 模板留 CSS 接口**（自定义模板 v1 不做，留口）。
- **不纳入（OUT / 顺延）**：
  - **公开链接 / 客户门户 / `unique_hash` 启用** → 顺延（v1 手动发 PDF）。
  - **自定义 PDF 模板 / 多模板** → 顺延（一套模板 + CSS 接口）。
  - **已读回执 / 在线 Accept** → 不做。
  - **批量发送 / 定时催款** → 顺延。

## 原子步骤草稿（JIT 时补全契约 / 测试 / 盲审要点）
> 切分意图：先把发票 PDF 渲染（含清洗）立稳，再叠报价/收据 PDF，再叠邮件发送 + Email log，最后前端 + 收尾。

1. **`services/pdf` 渲染核心 + 发票 PDF 模板 + 下载端点**：Jinja2 + WeasyPrint；**渲染前清洗**。盲审要点（待补）：所有用户输入经清洗（红线 7）、金额/税/合计与发票落盘值一致（不在 PDF 里重算）、无 SSRF（外链/图片）。
2. **报价 PDF + 收款收据 PDF**：复用模板族；收据挂 M7（未完成则跳过）。盲审要点（待补）：同模板口径、内容块/Notes 快照正确渲染。
3. **邮件发送 + Email log**：复用 M1 SMTP；正文模板 + 占位符；PDF 附件；Email log 表落地。盲审要点（待补）：复用 `services/email.py` 不另起一套、占位符注入安全、log 不泄漏 SMTP 凭证、发送失败可见。
4. **前端**：单据详情「下载 PDF」+「发送邮件」对话框（收件人/主题/正文预填）+ Email log 查看。盲审要点（待补）：前端不本地拼最终金额、附件来自后端渲染。
5. **收尾**：i18n（EN/ZH 模板 + 文案）、UX、里程碑级部署自测点。
