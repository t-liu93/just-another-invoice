## Goals and Scope
- **Goal**: Ability to create, edit, view, delete one quote; quote has independent numbering and validity period, auto-expire to `EXPIRED` (soft state, non-blocking); accepted quote converts to invoice in one click; quote/invoice editors can apply "bundled line item templates", include company-level "standard content blocks", insert "Notes templates".
- **IN**:
  - **Quote entity (isomorphic to invoice, option A)**: Mirror `quote` / `quote_line` / `quote_tax` / `quote_line_tax` four tables; **reuse `services/pricing` and `services/numbering`**; extract thin `services/_document.py` (or equivalent) helper at persistence layer for shared use by invoice/quote, no recalculation of money.
  - **Quote single state machine**: `DRAFT → SENT → {ACCEPTED, REJECTED, EXPIRED}` (drop `VIEWED`, no customer portal); `REJECTED` can edit and resend back to `SENT`; editable until `ACCEPTED`.
  - **Quote numbering**: Consume new `quote.numbering` setting (default template `{{SERIES:QUO}}-{{SEQUENCE:6}}`); use numbering engine with `document_type="QUOTE"` to allocate; company/customer sequence, gap handling, concurrency safety all reuse invoice setup.
  - **Quote validity period + auto-expire**: `quote.valid_until` (pre-filled by company default validity days on creation, editable); **APScheduler daily in-process task** sets `SENT` quotes with `valid_until < today` to `EXPIRED`; **read-time bottom-up** on get/list to prevent misses.
  - **EXPIRED soft state (author's "escape hatch")**: Expiry **never blocks**—expired quotes still convert directly; separate "reactivate / extend" action postpones `valid_until` and reverts to `SENT`.
  - **Convert quote→invoice**: Copy quote customer / lines / taxes / discount / treatment to new **`DRAFT` + `UNPAID` invoice** (`due_amount = total incl vat`, reuse M5 invoice creation logic, **no tax recalculation**); original quote becomes `ACCEPTED` with `converted_invoice_id` backlink, **not deleted**.
  - **Document content templates (bundled line items, named library)**: `document_template` + `document_template_line`; same service type can have multiple variants (e.g., "charging pole installation·Base / Intermediate / Very Complex"); `applies_to` marks quote/invoice/both; apply = **snapshot value-copy lines into editor** (snapshot; after apply all fields including price editable; modifying template doesn't affect already-issued documents).
  - **Standard content blocks (named library, company defaults + document override)**: `content_block` categorized by `kind` (warranty / T&C / bank info / payment terms), **multiple per category**, one per category can be default; quote/invoice **snapshot-override text** (pre-filled from default/selected block on creation, editable in document).
  - **Document Notes + Notes template**: Quote adds `notes` (invoice already has); `note_template` snippets named library, editor can insert in one click; separate from standard content blocks.
  - **Frontend**: Quote list + quote editor (mirror invoice); Convert / reactivate / validity UI; **quote and invoice editors share** "apply template / content block / insert Notes template" entry points; management pages (template / content block / Notes template CRUD).
- **OUT / defer to later**:
  - **Cost accounting / estimate → quote weak grouping** → M6.5 (this milestone only reserves "future additive source grouping column" space in `quote_line`, no implementation).
  - **Payment, partial / multi-stage payment (first/mid/final), `due_amount` flow with payment** → M7. M6 Convert only generates `UNPAID` invoice, payment binding all defers to M7 (`status` and `paid_status` already independent, "pay first installment without issuing invoice first" naturally holds).
  - **PDF rendering / email / public link** → M9; M6 content three blocks **only persist data**, store text/lines, PDF rendering defers to M9; `unique_hash` quote only reserve field, don't enable.
  - **Recurring Invoice** → v1 OUT (analysis doc §7.2.2).
  - **Quote clone / Invoice clone** → low priority follow-on.
  - **Multi-currency quotes / FX** → continue defer; quote currency = `company.base_currency`, `exchange_rate = 1`, `base_* = *` (same as M5).
  - **VAT report grid / ICP** → M10.

## This Round's Product & Technical Decisions (pre-agreed with author · 2026-06-11)
- [x] **Quote tables = option A**: Mirror invoice into four `quote_*` tables, **reuse pricing / numbering engines**, shared helper at persistence; **never backport to M5 live invoice tables** (zero risk). Isomorphism brings some ORM mapping duplication, acceptable (gains isomorphic diff per milestone, good for review).
- [x] **Quote no payment dimension**: `quote` contains no `paid_status` / `due_amount`; amounts go up to `total_incl_vat`.
- [x] **Quote state machine**: `DRAFT / SENT / ACCEPTED / REJECTED / EXPIRED` (single state). Editable window = not `ACCEPTED` (includes `EXPIRED`, `REJECTED`); `REJECTED` after edit can resend back to `SENT`.
- [x] **Convert semantics**: Manual action; can trigger from `SENT` / `ACCEPTED` / **`EXPIRED` (soft escape hatch)**; generates `DRAFT` + `UNPAID` invoice, reuse M5 invoice creation (get new number, run pricing engine, persist), original quote becomes `ACCEPTED` + `converted_invoice_id` backlink, not deleted.
- [x] **Expiry mechanism**: `valid_until` (company default days pre-fill, editable) + **APScheduler daily in-process task** + **read-time bottom-up**; `EXPIRED` is **soft state**, blocks no actions; separate "reactivate / extend" action.
- [x] **APScheduler is project's first background scheduler**: Use `AsyncIOScheduler`, start/stop in `main.py` `lifespan`; tasks idempotent (flip by condition only, don't depend on "exactly reaching today"); no inbound webhook entry (guard red line 9).
- [x] **Content three blocks all built as "named libraries"**: Document templates and standard content blocks both multi-entry (leave Base/Intermediate/… variant escape hatches); all applies are snapshot value-copies, editable post-apply.
- [x] **Document templates only carry line items**: v1 doesn't carry document-level defaults (tax mode / treatment still chosen by editor); fallback to refactor before launch if needed.
- [x] **Content three blocks shared by quote / invoice**: `content_block` override text columns and `notes` added simultaneously to `quote` (native) and `invoice` (additive migration); document template `applies_to` controls which document type can apply; M6 also supplements existing live invoice editor with "apply template / content block / insert Notes template" entry points.
- [x] **Quote single currency**: = `company.base_currency`, else `422` (same as M5).
- [x] **Create occupies number**: `POST /quotes` success immediately allocates `quote_number`; delete doesn't reclaim, gaps allowed (same as invoice).

## Pricing Rules
> Fully reuse M5 `services/pricing` convention (line subtotal → line discount → document discount → VAT → total; `quantize_money` 3 digits `ROUND_HALF_UP`; incl-vat / excl-vat reversal; treatment zero-ing effect). **M6 adds no new pricing rules**; quote is just "same pricing engine + one less payment dimension". Convert likewise reuses invoice creation pricing, **no tax recalculation**.

## State Machine Rules (M6 fixed)
- **Quote**: `DRAFT` (default post-create) ⇄ `SENT` (mark sent); `SENT/EXPIRED → REJECTED` (customer reject); `REJECTED → SENT` (edit and resend); `SENT/EXPIRED → ACCEPTED` (manual or Convert); `SENT → EXPIRED` (auto expiry / read-time bottom-up).
- **Editable window**: `status != ACCEPTED` permits `PUT`; `ACCEPTED` edit → `409` (already converted to invoice, edit invoice instead or reactivate first—`EXPIRED` not in this limit, expired still editable).
- **Expiry check**: Only for `SENT`; `valid_until` null → never expires. `EXPIRED` is soft state: Convert / edit / reactivate all allowed.
- **Convert precondition**: Quote `status ∈ {SENT, ACCEPTED, EXPIRED}` and `converted_invoice_id IS NULL`; after success that quote `ACCEPTED` and backlink filled, Convert again → `409`.
