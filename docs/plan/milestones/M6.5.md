# M6.5 · 成本核算 / 报价辅助（内部 estimation → 报价）（Costing / Estimation → Quote）

> 进入本里程碑前 JIT 产出。先读 `docs/plan/roadmap.md` 的 §2 全局约束 + M6.5 那一格；分析文档无专门的成本核算章节（本功能是 roadmap 后插的作者自用工作流，权威源头 = roadmap M6.5 格 + 本文与作者共定的决策）。
> **M4 已完成**：内部 `product` 目录（`purchase_cost_excl_vat` + `margin_rate` + `category.default_margin_rate` + `default_vat_rate_id` + `unit`），是本里程碑成本行的数据底座。
> **M5 已完成**：`services/pricing.compute_pricing`（纯函数，吃通用行/折扣/税）+ VAT treatment 推导 `derive_sales_vat_treatment`。
> **M6 已完成**：`quote` 四表 + `services/quote.create_quote`（取号 + pricing + 落库）+ 「套用模板 = 值拷贝快照」范式。M6 的 `quote_line` 已为本里程碑留好「未来 additive 加来源列」的空间，但**本里程碑不往报价表加任何来源/成本列**（见下）。
> **本里程碑的取向**：建一张**纯内部**的「成本 → 卖价」工作表（estimate），用一套**与税无关**的新算钱核心 `services/costing` 把成本反推卖价；再把估算行**分组**、每组**值拷贝**成一条**只含公开字段**的报价行，交给 M6/M5 出含税合计。estimate 是替掉作者现有 Excel 的工具——**轻量、独立、不进客户面**。

## 目标与范围
- **目标**：能创建、编辑、查看、删除一张**内部** estimate 工作表；每行 `Total = Price × Amount`、`Margin Amount = Total × Margin Rate`、`行卖价(excl) = Total + Margin Amount`，后端权威算出三个滚动汇总（Total Margin / Total Excl. VAT / 参考含税）；把估算行分组，一键**生成一张新 DRAFT 报价**（一组一行，只带公开描述 + 不含税卖价 + 税率），由 M6/M5 出 21% 含税合计——全程**客户面零泄漏**、**成本快照不漂移**。
- **纳入（IN）**：
  - **Estimate 实体（独立顶层工作表，轻量）**：`estimate`（根，挂 `company_id`）+ `estimate_line`（内部 cost/margin 行，cascade）+ `estimate_group`（客户面投影：公开描述 + 税率，一组 → 一条报价行，cascade）。**无正式编号、无状态机**（决策 Q4）：只有 `name` + 可选 `customer_id` + `notes` + 时间戳 + 一个 `generated_quote_id` 反链。
  - **统一行模型（不设行类型）**：labor / shipping / 差旅 / overhead 都是 `Margin Rate = 0` 的普通行（Price = 时薪/运费/单价），于是「Total Margin = 仅设备利润」自然落出（roadmap 钉死）。差旅、overhead 一般各挂单据级一行——只是约定，**不另建结构**。
  - **`services/costing` 权威计算（与税无关）**：纯函数算逐行 `line_total` / `margin_amount` / `line_sell_excl_vat`、滚动 `total_margin` / `total_excl_vat`、每组 `group_sell_excl_vat`；`Decimal` + `quantize_money`，**逐行舍入、合计由已舍入行汇总不二次舍入**（同 M5 口径）。**算钱逻辑必须单测**（红线 1）。
  - **成本快照**：`estimate_line` 落库时快照当时的 `unit_cost_excl_vat` + `margin_rate`（+ 算出的三个金额）；M4 目录后续改价/改 margin **不回灌**历史 estimate（护栏 2 / 红线 8）。
  - **参考含税（仅信息）**：read/preview 附带 `total_incl_vat_indicative = total_excl_vat × (1 + 标准税率)`（用公司当前标准 `vat_rate` 的 percent；无则省略）。**非权威、不落盘**——真正的含税口径只在生成出来的报价上由 M5 引擎算。
  - **estimation → 报价联动（生成新报价 / 值拷贝，决策 Q2）**：`POST /estimates/{id}/generate-quote` 把每个 group **值拷贝**成一条报价行（`name`=公开描述、`quantity`=1、`unit_price`=该组 Σ 行卖价(excl)、挂 group 的 `vat_rate_id`），组装 `QuoteWrite` 调 M6 `create_quote` 出一张新 `DRAFT` 报价；estimate 存 `generated_quote_id` 反链。**可重复生成**（每次产出一张新报价，反链刷新为最新）。
  - **分组报价行的税率（决策 Q3）**：每组手填**公开描述** + 选一个 `vat_rate_id`（前端默认带出该组内首个设备行的 `default_vat_rate`）；生成的报价走 **LINE 模式**，各组各挂税率（支持一单 21% / 9% 混用）。
  - **前端**：顶层导航加「成本核算 / Estimates」（像「产品」「报价」）；列表 + 编辑器（行表格：产品带出 or 自由填；逐行展示 Total / Margin Amount / 行卖价；三个滚动汇总；分组面板：圈行入组 + 每组公开描述 + 选税率 + 显示组卖价；「生成报价」按钮 → 建报价并跳转）。**产品选择复用 M4 内部 `GET /products`**（带 cost/margin，合法——estimate 本身是 owner-only 内部面）。
- **不纳入（OUT / 留到后续）**：
  - **往报价/发票表加「来源 estimate / 来源组」列** → 不做。反链**只挂 estimate 一侧**（`estimate.generated_quote_id`），报价表完全不感知 estimate，从结构上杜绝成本回链客户面（护栏 1 的结构性保证）。
  - **estimate 自己的编号 / 状态机 / 审批流** → 不做（决策 Q4，轻量）。`archived` 软标记等留作后续 additive。
  - **estimate↔quote 双向同步 / 强一一绑定** → 不做（弱关联，生成即值拷贝快照，互不联动）。
  - **同物多供应商比价 / 成本历史 / 报价毛利率反算报表** → 后续。
  - **AI 供货价单识别灌目录** → M8 之后 follow-on（复用视觉模型管道，给目录供数；与本里程碑解耦）。
  - **PDF / 邮件 / 公开链接**（生成出来的报价的渲染）→ M9；本里程碑只到「生成一张报价实体」为止。
  - **外币 estimate / FX** → 继续顺延；estimate 金额口径 = 公司本位币，无币种/汇率列（同 M5/M6）。
- **对应文档**：roadmap M6.5 / §2（红线 **1 / 2 / 3 / 7 / 8 / 10 / 12**）；M4（产品目录）/ M5（pricing + treatment 推导）/ M6（quote + 值拷贝范式）验收遗留项；记忆 `quote-assist-costing-feature` / `product-sku-upsert`。

## 本轮拟定的产品与技术决策（动手前已与作者共定 · 2026-06-11）
- [x] **Estimate = 独立顶层工作表**（决策 Q1）：自己的表 + 顶层导航 + CRUD + 「生成报价」动作；可选关联客户。不嵌在报价编辑器里。
- [x] **联动 = 生成新 DRAFT 报价 / 值拷贝 + 反链**（决策 Q2）：镜像 M6「套用模板 = 值拷贝快照」；可重复生成（每次新报价）；`estimate.generated_quote_id` 存最近一次反链做溯源。不推入当前编辑器、不强一一绑定。
- [x] **分组税率 = 每组手选、默认带组内首行 default VAT；生成走 LINE 模式**（决策 Q3）。公开描述每组手填。
- [x] **Estimate 轻量**（决策 Q4）：`name` + 可选 `customer_id` + `notes` + 时间戳 + 反链；无编号、无状态机。
- [x] **generate 前置 = estimate 必须已关联客户**：`customer_id IS NULL` → `422`（M6 `create_quote` 需客户做 VAT treatment 推导）。另每个**有行的组**必须有 `vat_rate_id`，否则 `422`；至少一组有行。
- [x] **报价表完全不感知 estimate**：不给 `quote`/`quote_line` 加任何来源/成本列；反链只在 estimate 一侧。
- [x] **estimate 编辑器复用 M4 内部产品 API**（`GET /products` 带 cost/margin）：estimate 是 owner-only 内部面，cost 可见合法；**零泄漏护栏只在 estimate→quote 边界生效**，不在 estimate 内部。
- [x] **舍入口径同 M5**：每行 `line_total` / `margin_amount` 各自 `quantize_money`（3 位 `ROUND_HALF_UP`），`line_sell_excl_vat = line_total + margin_amount`；滚动汇总 = 已舍入行/组值求和，**不二次舍入**。
- [x] **`margin_rate` 后端只快照不重解析**：前端在选品时把 `effective_margin_rate` 带进行、用户可改；后端**按收到的值落库**（缺省 0），保存时**不再回查目录**（快照诚实 + 简单，同 M5 对 `unit_price` 的处理）。
- [x] **金额一律 `Decimal` / `NUMERIC`**（红线 1）：`unit_cost_excl_vat` `NUMERIC(14,3)`（对齐 M4）；`quantity` `NUMERIC(18,3)`；`margin_rate` `NUMERIC(6,4)`；三个金额快照 `NUMERIC(18,3)`。
- [x] **参考含税仅信息、不落盘**：read 附 `total_incl_vat_indicative` + `indicative_vat_rate_percent`，UI 标注「参考」。

## 契约（先行 · 前后端各自对着写）
> 业务端点一律 `/api/v1/*`。改契约就 `npm run codegen` 重生成 `schema.d.ts`，CI drift 关强制无漂移（红线 11）。沿用 M1 cookie 会话 + `current_mfa_user`；owner-only 复用 `_owner_only`。所有写端点 `company_id` 由 service 注入。

**Estimate 预览（步骤 1）**
- `POST /api/v1/estimates/calculate` body `EstimateCalculationRequest` → `200 EstimateCalculationRead`。只算不落库。复用 `services/costing` 纯核心；返回逐行金额 + 每组卖价 + 三个滚动汇总（含参考含税）。

**Estimate CRUD / 列表（步骤 2）**
- `GET /api/v1/estimates` query `{q?, customer_id?, limit?=50, offset?=0, sort_by?: "name"|"created_at"|"updated_at"="updated_at"}` → `EstimateListResponse {items, total}`（`q` 搜 `name`，可带客户名 JOIN）。
- `POST /api/v1/estimates` body `EstimateWrite` → `201 EstimateRead`（落库 + costing 算 + 落 line/group 快照）。
- `GET /api/v1/estimates/{id}` → `200 EstimateRead`；跨公司 → `404`。
- `PUT /api/v1/estimates/{id}` body `EstimateWrite` → `200 EstimateRead`（重算 + 替换 line/group 子表）。
- `DELETE /api/v1/estimates/{id}` → `204`（DB cascade 删 line/group；不动已生成报价）。

**生成报价（步骤 3）**
- `POST /api/v1/estimates/{id}/generate-quote` → `201 QuoteRead`（每组 → 一条报价行，值拷贝公开字段，调 M6 `create_quote` 出新 `DRAFT` 报价；存 `generated_quote_id`；可重复生成新报价）。前置不满足（无客户 / 组缺税率 / 无任何分组行）→ `422`。

**核心 schema 形状**
- `EstimateLineInput { product_id?, name, description?, unit_cost_excl_vat, quantity, margin_rate?, unit_id?, unit_name?, group_ref? }`
  - `unit_cost_excl_vat >= 0`；`quantity > 0`；`margin_rate >= 0`（缺省 0）；`name`/`description` 是 `text`，**内部用**。
  - `product_id` 只作来源记录；`group_ref` = 客户端临时键，关联到同一 `EstimateWrite` 里某个 group（服务端解析成 `group_id` FK）。
- `EstimateGroupInput { ref: str, public_description, vat_rate_id?, sort_order? }`
  - `public_description` 是 `text`，**唯一会进报价的文本**；`vat_rate_id` 写时可空（草稿态），生成报价时校验非空。
- `EstimateWrite { name, customer_id?, notes?, groups: EstimateGroupInput[], lines: EstimateLineInput[] }`（行可不分组；`name` 必填）。
- `EstimateLineRead { id, group_id?, sort_order, product_id?, name, description?, unit_id?, unit_name?, unit_cost_excl_vat, quantity, margin_rate, line_total, margin_amount, line_sell_excl_vat }`（**内部全字段，owner-only**）。
- `EstimateGroupRead { id, sort_order, public_description, vat_rate_id?, vat_rate_label?, vat_rate_percent?, group_sell_excl_vat }`。
- `EstimateRead { id, name, customer_id?, customer_name?, notes?, total_margin, total_excl_vat, total_incl_vat_indicative?, indicative_vat_rate_percent?, generated_quote_id?, generated_quote_number?, lines[], groups[], created_at, updated_at }`。
- `EstimateListItem { id, name, customer_id?, customer_name?, total_excl_vat, total_margin, generated_quote_id?, updated_at }`。
- `EstimateCalculationRequest { groups: EstimateGroupInput[], lines: EstimateLineInput[] }` → `EstimateCalculationRead { lines: {sort_order, line_total, margin_amount, line_sell_excl_vat, group_ref?}[], groups: {ref, group_sell_excl_vat}[], total_margin, total_excl_vat, total_incl_vat_indicative?, indicative_vat_rate_percent? }`。

## 算钱规则（M6.5 钉死 · `services/costing`）
> 与税完全无关；schema 只校验形状，所有金额由 service 算。

- **逐行**：`line_total = quantize(unit_cost_excl_vat × quantity)`；`margin_amount = quantize(line_total × margin_rate)`；`line_sell_excl_vat = line_total + margin_amount`（两个已舍入值相加，天然 3 位）。
- **滚动汇总**：`total_margin = Σ margin_amount`；`total_excl_vat = Σ line_sell_excl_vat`；**由已舍入行值求和，不二次舍入**（同 M5）。
- **每组卖价**：`group_sell_excl_vat = Σ (该组行) line_sell_excl_vat`。未分组行不计入任何组（但计入 estimate 的 `total_*`）。
- **参考含税**：`total_incl_vat_indicative = quantize(total_excl_vat × (1 + standard_percent/100))`，`standard_percent` 取公司当前**标准** `vat_rate`（约定：active 的 21% 那条；可由设置/约定选定，实现时取「percent 最高的 active rate」或一条标注位，细化时钉死）；无可用标准 rate 则 `total_incl_vat_indicative = null`。**非权威**。
- **margin_rate 语义 = 成本加价率（markup-on-cost）**：`行卖价 = 成本 × (1 + margin_rate)`。labor/shipping/overhead 行 `margin_rate = 0` ⇒ 卖价 = 成本（时薪/运费即售价），故 Total Margin 只含设备行利润。

## 生成报价规则（M6.5 钉死 · 零泄漏护栏）
> 把 estimate 的 group 投影成报价行；**只搬公开字段**，cost/margin/时薪/内部名/product_id 一律不进。

- **前置校验**（不满足 `422`）：`estimate.customer_id` 非空；每个含行的 group 有 `vat_rate_id`；至少一个含行的 group。
- **每组 → 一条 `QuoteLineInput`**：`name = group.public_description`；`description = None`；`quantity = 1`；`unit_id/unit_name = None`（一口价，不暴露拆分）；`unit_price = group_sell_excl_vat`；`discount = NONE`；`vat_rate_id = group.vat_rate_id`；`product_id = None`。
- **组装 `QuoteWrite`**：`customer_id = estimate.customer_id`；`tax_mode = LINE`；`amounts_include_vat = False`（卖价是 excl）；`vat_treatment_id = None`（交给 `create_quote` 按客户推导，复用 M5 `derive_sales_vat_treatment`）；`quote_date = today`；`valid_until = None`（后端按公司默认天数预填）；`lines = [...]`（组顺序）。
- **落地**：调 `services/quote.create_quote` → 新 `DRAFT` 报价（占号 + pricing + 落库，**不重算成本**）；写回 `estimate.generated_quote_id`。再次调 → 产出**新**报价，反链刷新为最新；不删旧报价。
- **零泄漏断言（单测必覆盖）**：生成的报价及其行的任何序列化里，**不含** `unit_cost_excl_vat` / `margin_rate` / `line_total` / `margin_amount` / 内部 `name` / 内部 `description` / `product_id`。

## 数据模型 / 迁移
> UUID PK；根表挂 `company_id`（红线 2）；子表 FK cascade（红线 3）；金额列 `NUMERIC`；文本列 `text`（红线 10）。**一条 additive 迁移**：建 3 张表 + 索引；**不动 `quote`/`invoice` 任何列**。无新枚举。

- **`estimate`**（根，轻量）：`id`；`company_id` FK→`company.id`(`RESTRICT`) index；`name` text NOT NULL；`customer_id` FK→`customer.id`(`SET NULL`) nullable；`notes` text nullable；`generated_quote_id` FK→`quote.id`(`SET NULL`) nullable（反链）；`total_margin`/`total_excl_vat` `NUMERIC(18,3)`（落盘汇总）；timestamps。索引 `ix_estimate_company_id` / `ix_estimate_customer_id`。
- **`estimate_group`**（客户面投影）：`id`；`estimate_id` FK→`estimate.id`(`CASCADE`)；`sort_order` int；`public_description` text NOT NULL；`vat_rate_id` FK→`vat_rate.id`(`RESTRICT`) nullable；`group_sell_excl_vat` `NUMERIC(18,3)`（落盘）；timestamps。索引 `ix_estimate_group_estimate_id`。
- **`estimate_line`**（内部成本行）：`id`；`estimate_id` FK→`estimate.id`(`CASCADE`)；`group_id` FK→`estimate_group.id`(`SET NULL`) nullable；`sort_order` int；`product_id` FK→`product.id`(`SET NULL`) nullable（来源，删品不影响快照）；`name` text NOT NULL；`description` text nullable；`unit_id` FK→`unit.id`(`SET NULL`) nullable；`unit_name` text nullable；`unit_cost_excl_vat` `NUMERIC(14,3)` NOT NULL；`quantity` `NUMERIC(18,3)` NOT NULL；`margin_rate` `NUMERIC(6,4)` NOT NULL server_default `0`；金额快照 `line_total`/`margin_amount`/`line_sell_excl_vat` `NUMERIC(18,3)`；timestamps。索引 `ix_estimate_line_estimate_id` / `ix_estimate_line_group_id`。
- **删除安全**：删 estimate → DB cascade 删 line/group，但 `generated_quote_id` 只是反链，**不连带删报价**；删被引用的 `customer`/`product`/`unit`/`vat_rate` —— estimate 的弱引用 `SET NULL`（删产品/单位/品类不破坏 estimate_line 快照），`vat_rate` 在 group 上 `RESTRICT`（被未生成的 estimate_group 引用时拦删，保口径）。
- **RLS**：继续留口不开；服务层集中用当前用户 `company_id`。

## 🟢 部署自测点（里程碑验收 · 人工走）
> 本地集成：`docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build`；浏览器 `http://localhost:${APP_HOST_PORT:-8000}`。

1. **建 estimate + 统一行模型**：新建一张 estimate（名称 + 关联一个 NL 客户）；加几条设备行（**从 M4 产品带出** cost / margin / 单位 / 默认 VAT）+ 一条人工行（自由填，时薪 × 工时，margin 0）+ 一条运费行（margin 0）；逐行看后端算出的 `Total` / `Margin Amount` / `行卖价`；头部看 `Total Margin`（仅设备）/ `Total Excl. VAT` / 参考含税。
2. **成本快照不漂移**：去 M4 改某产品采购价或品类 margin → 回到老 estimate，行金额与汇总**不变**。
3. **分组**：把「设备 A + 配件」圈成一组（公开描述「Huawei 11kW 充电桩含安装」，选 21%），把「人工 + 运费」圈成另一组（选 21%）；看每组卖价 = 组内 Σ 行卖价。
4. **生成报价**：点「生成报价」→ 生成一张新 `DRAFT` 报价，**一组一行**：行名 = 公开描述、不含税价 = 组卖价、LINE 模式各挂税率；报价走 M5 出 21% 含税合计（= excl × 1.21）；estimate 页显示反链到该报价；再点一次生成 → 产出**另一张**新报价，反链刷新。
5. **客户面零泄漏**：打开生成出来的报价 / 其行 / 列表，**看不到任何** cost / margin / 时薪 / 内部行名 / 内部 description；报价行只有公开描述 + 价 + 税。
6. **生成前置边界**：把 estimate 的客户清空再点生成 → 被拒并提示「先关联客户」；某组不选税率 → 被拒。
7. **隔离 / cascade / restrict**：跨公司取 estimate `404`；删 estimate → DB cascade 删 line/group，但**已生成的报价不受影响**；删 M4 product / unit / category → 老 estimate 行金额快照仍在（FK `SET NULL`）。
8. CI 四关全绿；`schema.d.ts` 无漂移。
