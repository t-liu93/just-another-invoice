## Goals and Scope
- **Goal**: Deliver documents to customers — generate clean, fully-rendered, typographically stable PDFs (invoice / quote / payment receipt) downloadable by language; reuse M1 SMTP to send document emails + PDF attachments; keep Email log.
- **In Scope (IN)**:
  - **PDF generation**: One template family (**WeasyPrint + Jinja2**), renders company header/logo/customer address/line items/tax/totals/content blocks/Notes; **pre-render sanitization + anti-SSRF** (red line 7); output EN/ZH by language; download endpoint (**no public link; manual send**).
  - **Language**: `customer.locale` (customer-level default) + company default locale setting + export/send-time override; resolution chain fixed (see D2).
  - **Email**: Reuse M1 SMTP; extend to support **attachments + CC**; **company-level editable email templates** (subject + body, with placeholders; stored in settings table, red line 5); send dialog prefilled and editable; attach PDF; **Email log** (send record; no read-receipt).
  - **Payment receipt PDF** (low priority, step 4): Generate receipt PDF + download for a single payment.
  - **PDF template exposes CSS interface** (custom templates v1 not done; leave hook).
- **Out of Scope / Deferred (OUT)**:
  - **Public link / customer portal / `unique_hash` activation** → deferred (v1 send PDF manually).
  - **Custom / multiple PDF templates** → deferred (one template family + CSS interface).
  - **Read receipts / online Accept / pixel callback** → not doing.
  - **Bulk send / scheduled reminders / async queue** → deferred (small volume; sync send OK).
  - **PDF disk caching** → not doing (on-demand render, see D5).
  - **Receipt email send** → not doing (receipt download only; email only for invoice/quote).
  - **Dutch (NL) PDF** → not doing (v1 EN/ZH only, consistent with UI i18n).

## Frozen Decisions (D1–D8 · Implementation must follow; no deviation)

- **D1 · PDF engine = WeasyPrint** (HTML+CSS→PDF, pure Python, single-container friendly; try first, switch if needed). Two hard author requirements in implementation:
  1. **Multi-charset glyph support**: Docker runtime installs `fonts-noto-core` + `fonts-noto-cjk` (covers Latin / accented / CJK); PDF CSS uses font stack `"Noto Sans", "Noto Sans CJK SC", sans-serif` as fallback; ensures Chinese / Dutch accented chars / customer original text mixed-render with no tofu blocks.
  2. **Typographic stability**: Fixed A4 (`@page { size: A4; margin: ... }`), line items use `table` layout (not float), totals area right-aligned fixed column widths, long descriptions `word-wrap`; page-break header repeat (`thead { display: table-header-group }`).
- **D2 · PDF/email language = customer-level default + export override**. Add `customer.locale` (`en`/`zh`, nullable). **Resolution chain** (`resolve_document_locale`): `export/send-request locale override` → `customer.locale` → `company default locale setting` → `"en"`. **Don't add locale column on invoice/quote** — labels are template i18n (not user data); amounts already snapshotted; each export determines language via resolution chain on-the-fly; document itself doesn't persist language.
- **D3 · Payment receipt PDF included, low priority** (step 4); scope = **single payment one receipt** (no multi-payment combined receipts, deferred). Receipt download only, no email send.
- **D4 · Email templates = company-level editable, stored in settings table** (red line 5 typed). Settings key `email.templates` (COMPANY level), structure = `{doc_type: {locale: {subject, body}}}`, `doc_type ∈ {invoice, quote}`, `locale ∈ {en, zh}`. Body is **plain text + placeholders** (no arbitrary HTML stored); at send time: placeholder substitution + HTML escape + `nl2br` + wrap in minimal HTML shell. On first read when no value: fall back to **built-in default templates** (same fallback approach as SMTP/AI).
- **D5 · PDF renders on-demand, no disk cache**. Each download/send renders fresh (small volume, always reflects latest snapshot, no staleness/cleanup issues). Storage abstraction continues serving only M8 receipts; future caching would use it.
- **D6 · Email synchronous send, no auto-retry**. Send failure logged in Email log as `FAILED` + `error_message`; manual resend = create new log row. No queue, no webhook (red line 9).
- **D7 · Anti-SSRF / sanitization (red line 7)**:
  - WeasyPrint receives **custom `url_fetcher`**: only allows `data:` URIs; **rejects all `http(s)`/`file`/external links** (raises error); eliminates SSRF and local file reads triggered by template/user input.
  - **Logo embedded as `data:` URI** (instant base64 from `binary_asset.content`); no URL involved.
  - All user text fields pass **Jinja2 autoescape (ON)** before entering PDF/email HTML; v1 document fields are all plain text (no rich text); autoescape suffices; `nh3` (already a dependency) as email template body backstop sanitization layer (guards against author pasting HTML/scripts).
- **D8 · Test layering (key architecture constraint)**: Separate "construct HTML (pure function)" from "WeasyPrint binary HTML→PDF":
  - `build_*_html(...) -> str`: pure function, **default `pytest` unit test** (assert amounts = snapshot, escaping, locale label switching, `url_fetcher` rejects http). **No pango/cairo dependency**.
  - `html_to_pdf(html) -> bytes`: thin WeasyPrint wrapper, **`@pytest.mark.integration`** (assert output starts with `%PDF`); CI integration job needs system libs (see [CI/Docker Changes]).

## Data Model / Migrations

### New Column: `customer.locale` (Step 2, migration 0022)
- `customer.locale`: `String(5)`, nullable (`en` / `zh`; nullable = follow company default). Additive, no backfill needed (NULL means "follow default").

### New Table: `email_log` (Step 6, migration 0023)
- Audit record table; records every document email send attempt. **Normalized (red line 6)**: use generic `(related_type, related_id)` to reference documents; **don't hang multiple nullable FKs**.
- Columns:
  - `id` UUID PK
  - `company_id` UUID NOT NULL FK→`company.id` ON DELETE RESTRICT (red line 2, index)
  - `related_type` enum(`INVOICE`/`QUOTE`) NOT NULL
  - `related_id` UUID NOT NULL (soft reference, no FK: audit record persists after document deleted; index `(company_id, related_type, related_id)`)
  - `to_email` Text NOT NULL
  - `cc` Text nullable (comma-separated; or JSONB list — implementer chooses; default Text)
  - `subject` Text NOT NULL
  - `body_snapshot` Text NOT NULL (HTML body snapshot at send time)
  - `attachment_filename` Text nullable
  - `locale` String(5) nullable (language used for send; for audit reference)
  - `status` enum(`SENT`/`FAILED`) NOT NULL
  - `error_message` Text nullable (failure reason; **never write SMTP credentials**)
  - `creator_id` UUID nullable FK→`user.id` ON DELETE SET NULL
  - `created_at` / `sent_at` timestamptz
- **Don't store**: SMTP password / API key / storage paths (red line 7).

### Settings (no migration, JSONB value)
- `email.templates` (COMPANY level, `EmailTemplatesSetting`) — D4.
- Company default locale: use existing COMPANY-level settings container (implementation defines key; suggested `document.default_locale`, typed `DocumentDefaultsSetting{ locale: "en"|"zh" = "en" }`).

> `_enums.py` additions: `EmailRelatedType`(INVOICE/QUOTE), `EmailStatus`(SENT/FAILED).
