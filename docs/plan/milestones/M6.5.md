## Goals and Scope
- **Goal**: Ability to create, edit, view, delete one **internal** estimate worksheet; each line `Total = Price × Amount`, `Margin Amount = Total × Margin Rate`, `line sell price (excl) = Total + Margin Amount`, backend authoritatively calculates three rolling totals (Total Margin / Total Excl. VAT / indicative incl-vat); group estimate lines, one-click **generate new `DRAFT` quote** (one group → one line, only public description + excl-vat sell price + tax rate), M6/M5 produces 21% incl-vat total—full process **zero customer-facing leak**, **cost snapshot immutable**.
- **IN**:
  - **Estimate entity (independent top-level worksheet, lightweight)**: `estimate` (root, has `company_id`) + `estimate_line` (internal cost/margin lines, cascade) + `estimate_group` (customer-facing projection: public description + tax rate, one group → one quote line, cascade). **No formal numbering, no state machine** (decision Q4): just `name` + optional `customer_id` + `notes` + timestamps + one `generated_quote_id` backlink.
  - **Unified line model (no line type)**: labor / shipping / travel / overhead all normal lines with `Margin Rate = 0` (Price = hourly/shipping/unit price), so "Total Margin = equipment profit only" naturally falls out (roadmap fixed). Travel, overhead typically one line per document—just convention, **no separate structure**.
  - **`services/costing` authoritative calculation (tax-agnostic)**: Pure function calculates per-line `line_total` / `margin_amount` / `line_sell_excl_vat`, rolling `total_margin` / `total_excl_vat`, per-group `group_sell_excl_vat`; `Decimal` + `quantize_money`, **per-line rounding, totals by summing rounded lines no second rounding** (same as M5). **Costing logic must be unit-tested** (red line 1).
  - **Cost snapshot**: `estimate_line` on persist snapshots `unit_cost_excl_vat` + `margin_rate` (+ three calculated amounts); M4 catalog subsequent price/margin changes **don't backfill** historical estimates (guardrail 2 / red line 8).
  - **Indicative incl-vat (informational only)**: read/preview includes `total_incl_vat_indicative = total_excl_vat × (1 + standard_rate_percent)` (use company current standard `vat_rate` percent; if none omit). **Non-authoritative, not persisted**—real incl-vat only calculated on generated quote by M5 engine.
  - **Estimate → quote linkage (generate new quote / snapshot value-copy, decision Q2)**: `POST /estimates/{id}/generate-quote` snapshot value-copy each group into one quote line (`name`=public description, `quantity`=1, `unit_price`=that group Σ line sell price (excl), has group `vat_rate_id`), assemble `QuoteWrite` call M6 `create_quote` produce new `DRAFT` quote; estimate stores `generated_quote_id` backlink. **Repeatable generation** (each time produce new quote, backlink refresh to latest).
  - **Group quote line tax rate (decision Q3)**: Each group manually fill **public description** + choose `vat_rate_id` (frontend default show group's first equipment line `default_vat_rate`); generated quote uses **LINE mode**, each group has its tax rate (support one document 21% / 9% mix).
  - **Frontend**: Top-level nav add "Costing / Estimates" (like "Products" "Quotes"); list + editor (line table: product bring-in or free-form; per-line show Total / Margin Amount / line sell price; three rolling totals; grouping panel: circle lines into group + each group public description + choose tax rate + show group sell price; "generate quote" button → create quote and jump). **Product selection reuse M4 internal `GET /products`** (bring cost/margin, legal—estimate itself is owner-only internal).
- **OUT / defer to later**:
  - **Add "source estimate / source group" column to quote/invoice** → don't do. Backlink **only on estimate side** (`estimate.generated_quote_id`), quote table completely unaware of estimate, structurally prevent cost backlink to customer (guardrail 1 structural guarantee).
  - **Estimate's own numbering / state machine / approval flow** → don't do (decision Q4, lightweight). `archived` soft mark etc. defer to future additive.
  - **Estimate↔quote bidirectional sync / strong one-to-one binding** → don't do (weak association, generate snapshot value-copy, no mutual updates).
  - **Same item multi-vendor comparison / cost history / quote margin-rate reverse-calculate report** → later.

  - **PDF / email / public link** (rendering generated quote) → M9; this milestone only to "generate quote entity".
  - **Multi-currency estimate / FX** → continue defer; estimate amount = company base currency, no currency/exchange_rate columns (same as M5/M6).

## Pricing Rules (M6.5 fixed · `services/costing`)
> Completely tax-agnostic; schema only validates shape, all amounts calculated by service.

- **Per-line**: `line_total = quantize(unit_cost_excl_vat × quantity)`; `margin_amount = quantize(line_total × margin_rate)`; `line_sell_excl_vat = line_total + margin_amount` (two rounded values added, naturally 3 digits).
- **Rolling totals**: `total_margin = Σ margin_amount`; `total_excl_vat = Σ line_sell_excl_vat`; **sum of rounded line/group values, no second rounding** (same as M5).
- **Per-group sell price**: `group_sell_excl_vat = Σ (that group's lines) line_sell_excl_vat`. Ungrouped lines count into total, not into any group.
- **Indicative incl-vat**: `total_incl_vat_indicative = quantize(total_excl_vat × (1 + standard_percent/100))`, `standard_percent` take company current **standard** `vat_rate` (convention: active 21% line; can be selected by setting/convention, implement take "highest percent active rate" or one marked position, finalize later); if no standard rate available then `total_incl_vat_indicative = null`. **Non-authoritative**.
- **margin_rate semantics = cost markup-on-cost**: `line sell price = cost × (1 + margin_rate)`. labor/shipping/overhead lines `margin_rate = 0` ⇒ sell price = cost (hourly/shipping/unit is sale price), so Total Margin only contains equipment profit.

## Generate Quote Rules (M6.5 fixed · zero-leak guardrail)
> Project estimate groups into quote lines; **only move public fields**, cost/margin/hourly/internal name/product_id all excluded.

- **Preconditions** (not met → `422`): `estimate.customer_id` non-null; each group with lines has `vat_rate_id`; at least one group with lines.
- **Each group → one `QuoteLineInput`**: `name = group.public_description`; `description = None`; `quantity = 1`; `unit_id/unit_name = None` (flat price, don't expose breakdown); `unit_price = group_sell_excl_vat`; `discount = NONE`; `vat_rate_id = group.vat_rate_id`; `product_id = None`.
- **Assemble `QuoteWrite`**: `customer_id = estimate.customer_id`; `tax_mode = LINE`; `amounts_include_vat = False` (sell price is excl); `vat_treatment_id = None` (let `create_quote` derive by customer, reuse M5 `derive_sales_vat_treatment`); `quote_date = today`; `valid_until = None` (backend pre-fill by company default days); `lines = [...]` (group order).
- **Persist**: Call `services/quote.create_quote` → new `DRAFT` quote (allocate number + pricing + persist, **don't recalculate costing**); write back `estimate.generated_quote_id`. Call again → produce **new** quote, backlink refresh to latest; don't delete old quotes.
- **Zero-leak assertion (must test)**: Generated quote and its lines' any serialization **no contain** `unit_cost_excl_vat` / `margin_rate` / `line_total` / `margin_amount` / internal `name` / internal `description` / `product_id`.

## Data Model / Migration
> UUID PK; root table has `company_id` (red line 2); child tables FK cascade (red line 3); amount columns `NUMERIC`; text columns `text` (red line 10). **One additive migration**: build 3 tables + indices; **don't touch `quote`/`invoice` any columns**. No new enums.

- **`estimate`** (root, lightweight): `id`; `company_id` FK→`company.id` (`RESTRICT`) index; `name` text NOT NULL; `customer_id` FK→`customer.id` (`SET NULL`) nullable; `notes` text nullable; `generated_quote_id` FK→`quote.id` (`SET NULL`) nullable (backlink); `total_margin`/`total_excl_vat` `NUMERIC(18,3)` (persisted totals); timestamps. Indices `ix_estimate_company_id` / `ix_estimate_customer_id`.
- **`estimate_group`** (customer-facing projection): `id`; `estimate_id` FK→`estimate.id` (`CASCADE`); `sort_order` int; `public_description` text NOT NULL; `vat_rate_id` FK→`vat_rate.id` (`RESTRICT`) nullable; `group_sell_excl_vat` `NUMERIC(18,3)` (persisted); timestamps. Index `ix_estimate_group_estimate_id`.
- **`estimate_line`** (internal cost lines): `id`; `estimate_id` FK→`estimate.id` (`CASCADE`); `group_id` FK→`estimate_group.id` (`SET NULL`) nullable; `sort_order` int; `product_id` FK→`product.id` (`SET NULL`) nullable (source, delete product don't affect snapshot); `name` text NOT NULL; `description` text nullable; `unit_id` FK→`unit.id` (`SET NULL`) nullable; `unit_name` text nullable; `unit_cost_excl_vat` `NUMERIC(14,3)` NOT NULL; `quantity` `NUMERIC(18,3)` NOT NULL; `margin_rate` `NUMERIC(6,4)` NOT NULL server_default `0`; amount snapshots `line_total`/`margin_amount`/`line_sell_excl_vat` `NUMERIC(18,3)`; timestamps. Indices `ix_estimate_line_estimate_id` / `ix_estimate_line_group_id`.
- **Delete safety**: Delete estimate → DB cascade delete line/group, but `generated_quote_id` just backlink, **don't cascade delete quote**; delete referenced `customer`/`product`/`unit`/`vat_rate` — estimate's weak references `SET NULL` (delete product/unit/category don't break estimate_line snapshot), `vat_rate` on group `RESTRICT` (if unreleased estimate_group reference block delete, preserve logic).
- **RLS**: Continue leave off; service layer centralizes `company_id`.
