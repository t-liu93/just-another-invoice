## 目标与范围
- **目标**：把单据交付给客户——生成一套干净、字形完整、排版稳的 PDF（发票 / 报价 / 收款收据），可按语言下载；复用 M1 SMTP 把单据邮件 + PDF 附件发出，并留 Email log。
- **纳入（IN）**：
  - **PDF 生成**：一套模板族（**WeasyPrint + Jinja2**），渲染抬头/logo/客户地址/行项目/税/合计/内容块/Notes；**渲染前清洗 + 反 SSRF**（红线 7）；按语言出 EN/ZH；下载端点（**无公开链接、手动发**）。
  - **语言**：`customer.locale`（客户级默认）+ 公司默认 locale 设置 + 导出/发信时可覆盖；解析链固定（见 D2）。
  - **邮件**：复用 M1 SMTP，扩展支持**附件 + 抄送**；**公司级可编辑邮件模板**（主题 + 正文，含占位符，存设置表，红线 5）；发信对话框预填可改；把 PDF 作附件发出；**Email log**（发送记录，无已读回执）。
  - **收款收据 PDF**（低优，步骤 4）：对单笔 payment 出收据 PDF + 下载。
  - **PDF 模板留 CSS 接口**（自定义模板 v1 不做，留口）。
- **不纳入（OUT / 顺延）**：
  - **公开链接 / 客户门户 / `unique_hash` 启用** → 顺延（v1 手动发 PDF）。
  - **自定义 / 多套 PDF 模板** → 顺延（一套模板族 + CSS 接口）。
  - **已读回执 / 在线 Accept / 像素回调** → 不做。
  - **批量发送 / 定时催款 / 异步队列** → 顺延（量小，同步发送即可）。
  - **PDF 落盘缓存** → 不做（即时渲染，见 D5）。
  - **收据邮件发送** → 不做（收据仅可下载；发信仅发票/报价）。
  - **荷兰语（NL）PDF** → 不做（v1 仅 EN/ZH，与 UI i18n 一致）。

## 已冻结决策（D1–D8 · 实现期一律照此，不得偏移）

- **D1 · PDF 引擎 = WeasyPrint**（HTML+CSS→PDF，纯 Python，单容器友好；先试，不行再换）。两条作者硬要求落到实现：
  1. **多字符集字形支持**：Docker runtime 装 `fonts-noto-core` + `fonts-noto-cjk`（覆盖拉丁 / 重音 / CJK）；PDF CSS 用字体栈 `"Noto Sans", "Noto Sans CJK SC", sans-serif` 兜底，确保中文 / 荷兰语重音 / 客户原文混排不出豆腐块。
  2. **排版稳**：固定 A4（`@page { size: A4; margin: ... }`）、行项目用 `table` 布局（不用 float），合计区右对齐固定列宽，长描述 `word-wrap`；分页表头重复（`thead { display: table-header-group }`）。
- **D2 · PDF/邮件语言 = 客户级默认 + 导出覆盖**。新增 `customer.locale`（`en`/`zh`，nullable）。**解析链**（`resolve_document_locale`）：`导出/发信请求的 locale 覆盖` → `customer.locale` → `公司默认 locale 设置` → `"en"`。**不在 invoice/quote 上加 locale 列**——标签是模板 i18n（非用户数据）、金额已快照，每次导出按解析链即时决定语言即可；文档本身不持久化语言。
- **D3 · 收据 PDF 纳入、低优**（步骤 4）；范围 = **单笔 payment 一张收据**（不做多笔汇总收据，顺延）。收据仅下载，不发邮件。
- **D4 · 邮件模板 = 公司级可编辑、存设置表**（红线 5 类型化）。设置 key `email.templates`（COMPANY 级），结构 = `{doc_type: {locale: {subject, body}}}`，`doc_type ∈ {invoice, quote}`、`locale ∈ {en, zh}`。正文是**纯文本 + 占位符**（不存任意 HTML），发送时占位符替换 + HTML 转义 + `nl2br` + 套最小 HTML 外壳。首次读取无值时回落到**内置默认模板**（同 SMTP/AI 的 fallback 思路）。
- **D5 · PDF 即时渲染、不落盘缓存**。每次下载/发信现渲染（量小、永远反映最新快照、无陈旧/清理问题）。storage 抽象继续只服务 M8 收据；将来要缓存再接其口。
- **D6 · 邮件同步发送、不自动重试**。发送失败记 Email log `FAILED` + `error_message`；人工重发 = 新建一条日志行。无队列、无 webhook（红线 9）。
- **D7 · 反 SSRF / 清洗（红线 7）**：
  - WeasyPrint 传入**自定义 `url_fetcher`**：仅允许 `data:` URI，**拒绝一切 `http(s)`/`file`/外链**（抛错），杜绝模板/用户输入触发的 SSRF 与本地文件读取。
  - **logo 以 `data:` URI 内嵌**（从 `binary_asset.content` 即时 base64），不走任何 URL。
  - 所有用户文本字段经 **Jinja2 autoescape（ON）** 转义后再进 PDF/邮件 HTML；v1 单据字段均为纯文本（无富文本），autoescape 即足；`nh3`（已是依赖）作为邮件模板正文的兜底清洗层（防作者粘贴 HTML/脚本）。
- **D8 · 测试分层（关键架构约束）**：把「构造 HTML（纯函数）」与「WeasyPrint 二进制 HTML→PDF」分离——
  - `build_*_html(...) -> str`：纯函数，**默认 `pytest` 单测**（断言金额=快照、转义、按 locale 切标签、`url_fetcher` 拒绝 http）。**不依赖 pango/cairo**。
  - `html_to_pdf(html) -> bytes`：薄封装 WeasyPrint，**`@pytest.mark.integration`**（断言产出 `%PDF` 魔数）；CI 集成 job 需装系统库（见〔CI/Docker 变更〕）。

## 数据模型 / 迁移

### 新增列：`customer.locale`（步骤 2，迁移 0022）
- `customer.locale`：`String(5)`，nullable（`en` / `zh`；nullable = 跟公司默认）。additive，无回填需求（NULL 即「跟默认」）。

### 新增表：`email_log`（步骤 6，迁移 0023）
- 审计记录表，记录每一次单据邮件发送尝试。**规范化（红线 6）**：用泛型 `(related_type, related_id)` 引用单据，**不挂多个可空 FK**。
- 列：
  - `id` UUID PK
  - `company_id` UUID NOT NULL FK→`company.id` ON DELETE RESTRICT（红线 2，index）
  - `related_type` enum(`INVOICE`/`QUOTE`) NOT NULL
  - `related_id` UUID NOT NULL（软引用，不设 FK：审计记录在单据删除后仍保留；index `(company_id, related_type, related_id)`）
  - `to_email` Text NOT NULL
  - `cc` Text nullable（逗号分隔；或 JSONB 列表，实现期二选一，默认 Text）
  - `subject` Text NOT NULL
  - `body_snapshot` Text NOT NULL（发送当时的正文 HTML 快照）
  - `attachment_filename` Text nullable
  - `locale` String(5) nullable（发送所用语言，便于回看）
  - `status` enum(`SENT`/`FAILED`) NOT NULL
  - `error_message` Text nullable（失败原因；**绝不写 SMTP 凭证**）
  - `creator_id` UUID nullable FK→`user.id` ON DELETE SET NULL
  - `created_at` / `sent_at` timestamptz
- **不存储**：SMTP 密码 / API key / storage 路径（红线 7）。

### 设置（无迁移，JSONB value）
- `email.templates`（COMPANY 级，`EmailTemplatesSetting`）— D4。
- 公司默认 locale：复用既有 COMPANY 级设置承载（实现期定 key，建议 `document.default_locale`，typed `DocumentDefaultsSetting{ locale: "en"|"zh" = "en" }`）。

> `_enums.py` 新增：`EmailRelatedType`(INVOICE/QUOTE)、`EmailStatus`(SENT/FAILED)。

## 契约总览（先行 · 各步细化）
> 金额一律来自后端快照，PDF/邮件层**不重算**（红线 1）。所有端点 `company_id` 从登录用户注入，跨公司 → 404（红线 2）。owner-only（沿用现有 `current_mfa_user` + `_owner_only`）。

- `GET  /api/v1/invoices/{id}/pdf?locale=en|zh` → `application/pdf`（`Content-Disposition: attachment; filename="<number>.pdf"`）
- `GET  /api/v1/quotes/{id}/pdf?locale=en|zh` → `application/pdf`
- `GET  /api/v1/payments/{id}/receipt-pdf?locale=en|zh` → `application/pdf`
- `GET/PUT /api/v1/settings/email-templates` → `EmailTemplatesRead` / `EmailTemplatesUpdate`
- `GET/PUT /api/v1/settings/document-defaults`（默认 locale）→ `DocumentDefaultsRead/Update`（也可并入既有 preferences，实现期定）
- `POST /api/v1/invoices/{id}/send` — body `DocumentSendRequest{ to, cc?, locale?, subject?, body? }` → `EmailLogRead`
- `POST /api/v1/quotes/{id}/send` — 同上
- `GET  /api/v1/invoices/{id}/emails` / `GET /api/v1/quotes/{id}/emails` → `EmailLogListResponse`（按单据查日志）
- customer 既有 schema 增 `locale` 字段（GET/POST/PUT）

## 原子步骤清单
> 切分意图：先把**发票 PDF 渲染核心（含清洗/SSRF/字体）**立稳 → 叠**语言模型** → 叠**报价 PDF** → 叠**收据 PDF** → 叠**邮件模板** → 叠**邮件发送 + Email log** → **前端** → **收尾**。每步过 roadmap §5 DoD。

### 步骤 1 · `services/pdf` 渲染核心 + 发票 PDF 模板 + 下载端点（含 WeasyPrint/Docker/字体）
- **契约**：`GET /api/v1/invoices/{id}/pdf?locale=en|zh` → `application/pdf`（`Content-Disposition: attachment; filename`；locale 缺省 = `"en"`，智能默认在步骤 2 接上）。
- **依赖/构建**：
  - `pyproject.toml` 加 `weasyprint`（pin 版本）；`uv lock`。
  - Dockerfile runtime stage `apt-get install` WeasyPrint 系统库（`libpango-1.0-0 libpangocairo-1.0-0 libgdk-pixbuf-2.0-0 libffi8 libcairo2 shared-mime-info` 等）+ 字体（`fonts-noto-core fonts-noto-cjk`）。
  - CI：backend-quality 默认 `pytest` 不跑 WeasyPrint（D8）；集成 job 与 docker-build 需上述系统库（见〔CI/Docker 变更〕）。
- **后端**：
  - `services/pdf.py`：
    - `build_invoice_html(invoice, company, customer, locale, logo_data_uri) -> str`（纯函数）：组装上下文（公司抬头/地址/VAT/KvK、客户名+BILLING 地址、行项目快照、税行、合计、内容块/Notes 快照），Jinja2（autoescape ON）渲染 `templates/pdf/invoice.html`。**金额直接取快照，不算**。
    - `html_to_pdf(html) -> bytes`：WeasyPrint，传自定义 `url_fetcher`（仅 `data:`，其余抛错 — D7）。
    - `render_invoice_pdf(session, invoice_id, company_id, locale) -> (bytes, filename)`：load（含 lines/taxes，selectin）+ logo→data URI + build_html + html_to_pdf。
    - 后端标签 i18n：`PDF_LABELS: dict[locale, dict[key,str]]`（不复用 vue-i18n；后端自带 EN/ZH 标签表）。
  - `templates/pdf/invoice.html` + `templates/pdf/base.css`（A4、表格布局、字体栈 — D1）。
  - `api/pdf.py`（或挂进 `api/invoices.py`）：薄路由，404/owner 规则沿用。
- **前端**：本步不做（端点可 curl 验证；前端按钮在步骤 7）。
- **迁移**：无。
- **测试**：
  - 单测（默认）：`build_invoice_html` — ① 合计/税/行金额 == 发票快照（断言不重算）；② XSS 字段（name/description/notes 含 `<script>`）被转义；③ `locale=zh` 标签切中文、`en` 切英文；④ `url_fetcher` 对 `http://`/`file://` 抛错、对 `data:` 放行；⑤ 无 logo / 有 logo（data URI 内嵌）两路；⑥ 跨公司 → 404。
  - 集成（`integration`）：`html_to_pdf` 产出以 `%PDF` 开头、字节非空。
- **盲审要点**：PDF 不重算金额（只读快照）；所有用户输入经 autoescape；`url_fetcher` 阻断外链/本地文件（反 SSRF）；logo 仅 data URI；company_id 注入、跨公司 404；WeasyPrint 仅在 `html_to_pdf` 内导入（懒导入，默认单测不依赖系统库）。

### 步骤 2 · 客户 locale + 公司默认 + 语言解析链
- **契约**：customer GET/POST/PUT 增 `locale: "en"|"zh"|null`；`GET/PUT /settings/document-defaults`（默认 locale）；步骤 1 的 `/pdf` 端点 locale 缺省改为走解析链。
- **后端**：
  - 迁移 0022：`customer.locale String(5) nullable`。
  - `customer` model/schema 加 `locale`。
  - `DocumentDefaultsSetting{ locale }` typed 设置 + `services/settings` 读写（红线 5）。
  - `services/pdf.resolve_document_locale(override, customer, company_default) -> "en"|"zh"`（D2 解析链）；PDF/发信端点 locale 缺省时调用之。
- **前端**：customer 编辑器加 locale 选择（可空=「跟默认」）；设置面板加「文档默认语言」项（小改）。
- **迁移**：0022。
- **测试**：单测 `resolve_document_locale` 四档优先级（override>customer>company>en）；customer CRUD 带 locale 往返；默认设置读写 + 非法值拒绝。
- **盲审要点**：解析链顺序与 D2 一致；locale 取值约束（仅 en/zh/null）；设置类型化（无 stringly-typed）；契约改 → `schema.d.ts` 重生成无漂移。

### 步骤 3 · 报价 PDF + 下载
- **契约**：`GET /api/v1/quotes/{id}/pdf?locale=` → `application/pdf`。
- **后端**：`build_quote_html` + `render_quote_pdf`（复用 `html_to_pdf` / 标签表 / base.css）；`templates/pdf/quote.html`（与发票同构，标题/字段差异：报价号、有效期 valid_until、无 due/收款）；薄路由。
- **前端**：步骤 7 统一加。
- **测试**：同步骤 1 的单测口径（金额=快照、转义、locale、SSRF），针对报价字段；集成 `%PDF`。
- **盲审要点**：与发票同口径；报价特有字段（有效期/状态）正确；不渲染任何 costing/margin（M6.5 客户面零泄漏护栏延伸）；内容块/Notes 快照正确。

### 步骤 4 · 收款收据 PDF + 下载（低优 · D3）
- **契约**：`GET /api/v1/payments/{id}/receipt-pdf?locale=` → `application/pdf`（单笔 payment 一张收据）。
- **后端**：`build_payment_receipt_html` + `render_payment_receipt_pdf`；`templates/pdf/receipt.html`（公司抬头 + 客户 + 关联发票号 + 收款日/金额/方式 + 该发票当前 paid/due 快照）；薄路由。
- **前端**：收款面板（`InvoicePaymentPanel.vue`）加「下载收据」（步骤 7）。
- **测试**：单测 build（金额=payment 快照、转义、locale、SSRF）；集成 `%PDF`；跨公司 404。
- **盲审要点**：金额取 payment / invoice 快照不算；company_id 注入；收据不发邮件（仅下载）。

### 步骤 5 · 邮件模板（公司级可编辑，存设置表）+ 占位符引擎 + 设置 UI
- **契约**：`GET /api/v1/settings/email-templates` → `EmailTemplatesRead`；`PUT` ← `EmailTemplatesUpdate`。
- **后端**：
  - `schemas/setting.py`：`EmailTemplate{ subject, body }`、`EmailTemplatesSetting{ invoice:{en,zh}, quote:{en,zh} }`；key 常量 `SETTING_KEY_EMAIL_TEMPLATES`。
  - 内置默认模板（EN/ZH，带占位符）作 fallback（D4）。
  - `services/email.render_email_template(template, context) -> (subject, html_body)`：**占位符替换**（显式 token 表，见下）+ 值 HTML 转义 + `nl2br` + 套最小 HTML 外壳；正文先经 `nh3` 兜底清洗（D7）。
  - 占位符目录（缺失值替换为空串，不抛错）：`{COMPANY_NAME} {CUSTOMER_NAME} {DATE} {DOCUMENT_NUMBER} {TOTAL} {CURRENCY}`；发票另有 `{INVOICE_NUMBER} {DUE_DATE} {AMOUNT_DUE}`；报价另有 `{QUOTE_NUMBER} {VALID_UNTIL}`。
  - settings 端点（owner-only，COMPANY 级）。
- **前端**：设置面板新增「邮件模板」分类——按 doc_type×locale 编辑主题/正文 + 占位符提示，保存。
- **迁移**：无（JSONB 设置）。
- **测试**：单测占位符替换（含缺失占位符、含特殊字符转义、`nl2br`）；模板按 doc_type×locale 解析 + fallback 到内置默认；非法结构拒绝。
- **盲审要点**：正文是纯文本+占位符（不存任意 HTML）；值转义防注入；`nh3` 兜底；占位符未知/缺失不崩；设置类型化（红线 5）；契约改 → 重生成 schema 无漂移。

### 步骤 6 · 邮件发送（复用 SMTP，加附件/抄送）+ Email log 表 + 发送/日志端点

## 🟢 部署自测点（里程碑末一次性人工审计）
> 开发态：`docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d`（含 WeasyPrint 系统库/字体）。

1. **发票 PDF**：建一张多行、多税率、含内容块/Notes 的发票 → 下载 PDF；核对抬头/logo/客户地址/行项目/税/合计/内容块/Notes **与界面一致**；金额与发票快照一致（未重算）。
2. **字形/排版（D1 硬要求）**：中文行描述 + 荷兰语重音 + 长描述混排 → PDF **无豆腐块、不串行、不溢出、分页表头重复**。
3. **语言**：同一发票 `locale=zh` 与 `locale=en` 下载 → 标签切换正确、行内容（用户原文）不变。
4. **客户级默认 + 覆盖**：给某客户设 `locale=zh`，其发票默认中文；导出对话框临时切英文 → 生效。
5. **报价 PDF**：同口径下载；确认**不出现任何 cost/margin/时薪**（M6.5 护栏延伸）。
6. **收据 PDF**：对一张已收款发票的某笔 payment 下载收据；金额/关联发票/paid/due 正确。
7. **邮件模板**：设置面板编辑发票邮件中文模板（带占位符）并保存 → 重开发送对话框预填渲染正确。
8. **发送 + Email log**：用 M1 配好的 SMTP 把发票邮件 + PDF 附件发出（含抄送）；收到邮件、附件可开；单据 Email log 出现一条 SENT；故意填错 SMTP → 出现 FAILED + 错误信息且**不泄漏凭证**。
9. **反 SSRF/清洗**：在行描述/Notes 塞 `<script>`/外链 `<img src=http://…>` → PDF 中被转义、不发起外链请求（url_fetcher 阻断）。
10. **CI 四关绿** + `schema.d.ts` 无漂移 + `docker build` 通过。
