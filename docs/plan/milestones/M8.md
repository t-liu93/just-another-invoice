## 依赖与定位
- **依赖**：M2（本位币）+ M4（开支分类 `expense_category`、收款方式、币种）；可选挂 M3 客户。**不依赖发票/报价/收款**——是 roadmap §4 的「开支独立线」，拿到 M4 即可与单据线（M5/M6/M7）并行。
- **与其它里程碑的接口**：
  - **复用 M1/M2 既有 `binary_asset`**（`models/binary_asset.py`）+ storage 抽象做**收据上传**；该 storage 抽象**与 M9 PDF 落盘共用**——M8 先立、M9 复用。
  - **复用 M6 的定时基建**（报价到期那套 APScheduler）做**周期性开支自动生成**。
  - **AI 视觉管道**（票据识别）= M8 立的基建；其 **follow-on「AI 供货价单识别 → 灌 M4 产品目录」**复用同管道，给 M6.5 成本核算供数（见记忆 [[quote-assist-costing-feature]]）。
  - `expense_category.default_deductible`（M4 已建列）→ M8 每笔开支「是否可抵扣」的默认来源。
  - **下游**：M10 报表要 M8 的开支数据（进项 VAT 2a/4b/5b、开支报表、P/L）。

## 目标与范围
- **目标**：能记一笔开支并智能填单（拍票据 → 视觉大模型自动填净额/税额/税率/供应商/日期/分类）；固定成本按周期自动生成；每笔标是否可抵扣。
- **纳入（IN）**：
  - **Expense 实体 + CRUD + 列表**：挂 `company_id`；分类（M4）；供应商（文本或可选客户/供应商引用）；**净额 + 进项税额分存**（§7.4.1）；税率/VAT 处理类别（进项侧，数据驱动）；币种（v1 本位币）；**是否可抵扣**（默认取分类 `default_deductible`，可逐笔覆盖）；备注。
  - **收据上传**：图片/PDF，复用 `binary_asset` + storage 抽象（本地存储，路径/体积上限可配）；缩略图/下载。
  - **周期性开支**：模板 + 周期（月/季/年）→ 定时克隆出新开支（复用 M6 APScheduler）；可暂停。
  - **⭐ AI 票据智能填写**：票据图 → 视觉大模型 → 解析出 `ExpenseInput` 预填（净额/税额/税率/供应商/日期/分类建议）；**外部依赖：Claude 视觉模型 API**（最新模型按 `claude-api` skill 现查，默认 Claude）；调用凭证走 M2 类型化设置 + at-rest 加密（红线 5/9）。
  - **（follow-on）⭐ AI 供货价单识别 → 灌 M4 产品目录**：复用本里程碑视觉管道，把供应商价格单（图/PDF/Excel）→ 识别 → 按 SKU upsert 进 `product`（见记忆 [[product-sku-upsert]]）；**排在 AI 基建落地之后**，与开支主线解耦。
- **不纳入（OUT / 顺延）**：
  - 银行流水自动导入开支 → vNext（roadmap §4.x）。
  - 多币种开支 / 开支侧 FX → 顺延（同单据线单一本位币口径）。
  - 进项 VAT 申报聚合（2a/4a/4b/5b）→ M10（M8 只把净额/税额/类别/可抵扣**存对**，聚合在 M10）。

## 原子步骤草稿（JIT 时补全契约 / 测试 / 盲审要点）
> 切分意图：先把「记账数据底座 + 算钱/分存正确」立稳（可独立单测），再叠收据存储、周期生成、AI 智能填写，最后前端 + 收尾。AI 与外部模型相关的技术细节**到 JIT 时才钉死**。

1. **Expense 模型 + 迁移 + `services/expense` CRUD + schemas**：分类/供应商/净额+进项税额分存/可抵扣/币种；**净额↔税额一致性校验在后端**（算钱口径单测）。盲审要点（待补）：金额 `Decimal`、`company_id` 收敛、`text` 列、可抵扣默认来自分类。
2. **收据上传 + storage 抽象**：`binary_asset` 复用；上传/缩略图/下载/删除；storage 接口为 M9 共用预留。盲审要点（待补）：MIME/体积校验、路径不可穿越（红线 7）、删开支级联删附件（红线 3）。
3. **周期性开支**：模板 + 周期 + APScheduler 定时生成（复用 M6）。盲审要点（待补）：定时幂等、暂停/上限、生成口径。
4. **⭐ AI 票据智能填写**：视觉模型管道 + 解析 → 预填 `ExpenseInput`（不直接落库，人工确认后才存）；凭证走 M2 设置。盲审要点（待补）：外部调用失败回退手填、PII/票据图清洗、凭证不入日志、用 `claude-api` skill 现查模型 id。
5. **前端 + 收尾**：开支列表/编辑器/收据预览/周期管理/「拍票据自动填」入口；i18n；里程碑级部署自测点。
6. **（follow-on）AI 供货价单 → M4 目录**：复用步骤 4 管道；按 SKU upsert（[[product-sku-upsert]]）；可独立成一轮。
