# M2.5 · 设置入口统一 + 设置 UX 重构（Affine 式可展开面板）

> 进入本里程碑前 JIT 产出（**lean 版**）。范围与边界以 `docs/plan/roadmap.md` 的 M2.5 那一格为准——本文不重复其论证，只把**已定决策 + 原子步骤**钉死。
> **纯前端重构**：不动后端契约、不碰算钱、无迁移；非阻塞，可与 M3/M4 并行。依赖 M2（公司档案 + 三层设置已落地）。
> **本里程碑由单个 agent（Claude）端到端实现，不 fan-out。**

## 目标与范围
- **目标**：把目前散落、图标语义混乱的设置入口收敛成「右上角**一个齿轮 → 一个 Affine 式模态设置面板**」（左侧分类、右侧就地编辑）；业务主体身份留在独立的 **Company icon** 下，与设置面板职责不重叠。
- **现状（重构前 · 已摸排）**：`Dashboard.vue` / `Preferences.vue` / `SmtpSettings.vue` / `CompanyProfile.vue` 各自复制一套顶栏，入口散成：
  - 🏢 `BusinessOutline` → `/settings/company`（公司档案，尚算对）
  - 👤 `PersonOutline` → `/settings/preferences`（其实只有主题，人头 ≠ 偏好）
  - ⚙ `SettingsOutline` → `/settings/smtp`（齿轮只通向 SMTP，语义错位）
  - ☀/🌙 顶栏直切主题（与 Preferences 页**重复**）
  - 🌐 顶栏直切语言
- **纳入（IN）**：
  - **单一齿轮入口 + Affine 式模态面板**（见「已定决策」）：左侧分类导航 + 右侧详情就地编辑。
  - **分类收编**：① 偏好 Preference（语言 + 未来默认值占位）；② 邮件 SMTP（复用现有接口）；③ 主题 Theme（把顶栏散落的主题开关整合进来）；④ AI（**仅留分类占位、disabled / "soon"**，不实现功能）。
  - **顶栏收敛**：右上角只剩 **⚙ 齿轮（开面板）+ 🏢 Company（→ 公司档案）+ 🌐 语言快捷 + 邮箱 tag + 登出**；移除散落的 👤 人头入口与独立 ☀/🌙 主题开关（主题进面板）。
  - **去重 / 共享**：抽 `AppHeader` 共享顶栏，消掉四个视图各抄一份的重复；SMTP / 主题表单抽成可复用内容组件，供面板与（onboarding 的）路由壳共用。
- **不纳入（OUT）**：
  - **不新增任何后端字段 / 接口**（红线：纯前端；若契约确需对齐也只重生成 `schema.d.ts`，本里程碑预期为零改动）。
  - **业务主体身份**（抬头 / logo / VAT / 地址 / 本位币 / 编号规则）**不进齿轮面板**——留在 `/settings/company`，由 🏢 Company icon 进入。
  - 自定义主题、多公司切换、AI 设置的**具体功能**（本里程碑只留 AI 分类占位）。
- **对应文档**：roadmap M2.5 格 + §2 红线 7（渲染/输入清洗，本里程碑无新输入面）。

## 已定决策（动手前定 · 本轮已拍板）
- [x] **面板形态 = 模态浮层（Affine 式，作者已选）**：点齿轮弹出**居中浮层、背景变暗**，左侧 `n-menu` 分类 + 右侧详情就地编辑，`×` / 点遮罩关闭。**不是纯 Dropdown、不是整页路由、不是侧抽屉。**
- [x] **面板挂载在 `App.vue`**（在 `n-config-provider` / message / dialog provider 之内、与 `router-view` 平级）——全局浮层，任意页面可叠加；开关用一个**模块级单例 composable `useSettingsPanel()`**（`open(category?)` / `close()` / `activeCategory`），与 `useTheme` 同款单例模式。
- [x] **分类集**：`preference` / `smtp` / `theme` / `ai`（`ai` 项 disabled + "soon" 标记）。默认进面板停在 `preference`。
- [x] **语言双入口**：顶栏保留 🌐 快捷切换（便捷）+ 面板「偏好」分类内放语言设置（规范位）——与作者选定的 mockup 顶栏一致。**主题不再放顶栏**，只在面板「主题」分类。
- [x] **路由处置**：
  - `/settings/preferences`：**删除**（功能并入面板）。
  - `/settings/smtp`：**保留**——onboarding 流程依赖它（路由守卫放行 `smtp-settings`、`Onboarding.vue` 跳 `?from=onboarding`）；降级为 **onboarding 专用薄壳**，渲染抽出来的 SMTP 表单组件 + 「返回引导」。post-onboarding 的 SMTP 编辑改走面板。
  - `/settings/company`：**保留**（Company icon 目标，业务身份页，不进面板）。
- [x] **复用拆分**：从 `SmtpSettings.vue` 抽 `SmtpSettingsForm.vue`（载入/保存/测试逻辑 + 表单体，不含顶栏）；主题选择抽成面板内 `ThemeSettings` 片段（复用 `useTheme`）。
- [x] **零后端改动**：沿用 M1/M2 的 `GET/PUT /settings/smtp`、`/settings/smtp/test`、`GET/PUT /settings/me`；不碰 `schema.d.ts`（如无意外不应产生 drift）。

## 契约
- **无新端点。** 沿用 M1/M2 既有契约。预期 `schema.d.ts` **零变更**（若 codegen 仍报 drift 视为异常，需查清来源）。

## 数据模型 / 迁移
- **无。** 纯前端。

## 原子步骤清单
> 每步 = 一个原子前端改动，过 roadmap §5 DoD（本里程碑后端无关项天然通过；重点：`npm run build` 绿、`schema.d.ts` 无漂移、走得到部署自测点）。

### 步骤 1 · 面板骨架 + 可复用内容组件 + 开关 composable
- `composables/useSettingsPanel.ts`：模块级单例（`isOpen` / `activeCategory` / `open(category?)` / `close()`）。
- `components/settings/SettingsPanel.vue`：`n-modal`（或 `n-card` 包裹的居中浮层）+ 左侧 `n-menu` 分类（preference / smtp / theme / ai-soon）+ 右侧详情 slot/区；`×`、遮罩关闭。
- 抽内容组件：`components/settings/SmtpSettingsForm.vue`（从 `SmtpSettings.vue` 抽载入/保存/测试 + 表单体）；`components/settings/ThemeSettings.vue`（主题 radio，复用 `useTheme`）；`components/settings/PreferenceSettings.vue`（语言；未来默认值占位）。
- 在 `App.vue` 挂 `<SettingsPanel/>`（providers 内、与 `router-view` 平级）。
- **测试 / 自检**：`npm run build` 通过；面板能 `open()/close()`、四分类可切换、AI 分类 disabled。

### 步骤 2 · 顶栏收敛 + 共享 AppHeader
- `components/AppHeader.vue`：⚙（`useSettingsPanel().open()`）+ 🏢（→ `/settings/company`）+ 🌐 语言 + 邮箱 tag + 登出；**去掉 👤 人头与 ☀/🌙 顶栏主题开关**。
- `Dashboard.vue` 与 `CompanyProfile.vue` 改用 `AppHeader`（消重复顶栏）。
- **测试 / 自检**：右上角只剩 ⚙ + 🏢 + 🌐 + 登出；点 ⚙ 开面板；🏢 进公司档案；公司档案页也能从 ⚙ 开面板。

### 步骤 3 · 路由清理 + onboarding 薄壳 + i18n + 自测点
- 删 `/settings/preferences` 路由 + `Preferences.vue`。
- `SmtpSettings.vue` 降为 onboarding 薄壳：渲染 `SmtpSettingsForm` + 「返回引导」，保留 `?from=onboarding` / 回程 `?resume=done` 语义；确认路由守卫与 onboarding 流不破。
- i18n：新增/迁移 `settings.panel.*` 等文案进 `en.json` / `zh.json`（沿用既有 `settings.preferences.*` / `settings.smtp.*` key，避免无谓改 key）。
- 走「🟢 部署自测点」。
- **测试 / 自检**：onboarding 全流程（注册 → MFA → 公司档案 → 可跳过 SMTP → 完成）不破；`npm run build` 绿；`schema.d.ts` 无漂移。
